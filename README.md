## 🚀 Projetos em destaque

**Detecção de Anomalias em Tempo Real** · [repositório](https://github.com/dev-rafaelsilva/api-multi-profissional)
Pipeline de transações com Apache Kafka (KRaft): a API responde `202` na hora e consumers em background classificam o risco (LOW → CRITICAL) por valor, frequência, horário e falhas consecutivas. Métricas P50/P95/P99 no Prometheus + Grafana, schema versionado com Flyway.
`Java 21 · Spring Boot · Kafka · PostgreSQL · Prometheus · Grafana · Docker`

**PayReconcile** · *em desenvolvimento*
Conciliação automática de pagamentos de vários gateways (Mercado Pago, Stripe, Pix) em 4 microsserviços. Webhooks com idempotência em duas camadas, comunicação 100% assíncrona via RabbitMQ com dead-letter queue e um banco por serviço.
`Java · Spring Boot · RabbitMQ · PostgreSQL · Docker`

**secretscan** · [repositório](https://github.com/dev-rafaelsilva/CLI-Golang)
CLI em Go que procura segredos expostos (chaves de API, senhas, tokens) no código e também no histórico de commits. Roda 100% local e dá para colocar no CI/CD para barrar merges.
`Go · CLI · CI/CD`

**HubFlow** · *em desenvolvimento*
SaaS que junta várias contas do Notion num só dashboard, com OAuth 2.0 e sincronização em tempo real. Validado com um cliente real.
`Next.js · NestJS · TypeScript · MySQL · OAuth 2.0 · Flutter`
